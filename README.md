# ペーパーブリッジ・タイマー

1枚の紙で作った橋の上に紙コップを置き、電池（おもり）を何本入れても耐えられるかを競うコンテスト用のタイマーです。

## 使い方

`index.html` をブラウザで開くだけで使えます（インターネット接続があるとフォントがきれいに表示されます）。

- スタートを押すとF1風のシグナルが5つ点灯し、消えたら計測開始
- 「電池を入れる」5秒 → 「耐える！」3秒 をくり返し、耐えきるたびに1本カウント
- 橋が崩れたら「崩壊！」で記録を表示
- 秒数はスタート前に変更できます

## キー操作

| キー | 動作 |
| --- | --- |
| Space | スタート／一時停止／再開 |
| Enter | 崩壊（記録を確定） |
| R | リセット |
| M | BGMのオン／オフ |

BGMはブラウザ上で合成しているオリジナル曲です。
